# AI Usage Report

## Project: Fee Management & Reconciliation System

AI tools were used only to a limited extent during the development of this
project.

The majority of the project was developed independently, including the
Spring Boot backend structure, entities, repositories, services, controllers,
database integration, authentication, fee management, payment functionality,
and API testing.

AI was mainly used for occasional technical guidance when I faced a specific
issue or needed clarification.

### Areas where AI was used

- Understanding a few Spring Boot/JPA errors.
- Getting clarification on JWT authentication and Bearer tokens.
- Guidance on keeping the database password and JWT secret outside the
  GitHub repository.
- Occasional Git/GitHub guidance while preparing the project for submission.
- Reviewing some documentation and submission requirements.

### Areas developed independently

The main implementation was developed by me, including:

- Spring Boot project setup
- MySQL database configuration
- Entity and relationship design
- Repository layer
- Service layer
- REST controllers
- Authentication and authorization
- JWT implementation
- Fee calculation
- Student fee management
- Payment management
- Receipt management
- Outstanding fee handling
- Dashboard APIs
- Reconciliation APIs
- API testing using Postman

### Validation

The application was run and tested locally. API responses, database records,
authentication, and protected APIs were verified during development.

AI suggestions were only used as guidance when required, and the final
implementation was reviewed and tested in the actual project.

## Summary

AI was used minimally as a supporting tool during this assignment. It was not
used to generate the complete application. The majority of the development,
implementation, testing, and debugging was completed independently.
